# Minecraft Give 高版本指令生成器

一个基于 Python tkinter 的图形化工具，用于生成 Minecraft Java 版（1.20.5-1.21.11）物品组件格式的 `/give` 命令。支持多种物品组件，如附魔、属性修饰符、药水效果、烟花、头颅、食物、旗帜、工具、装备、成书等，并允许用户通过修改 `txt_files` 目录下的文本文件自定义 ID 映射。
## 功能特性

- **显示属性**：自定义名称、颜色、粗体/斜体、描述（Lore）。
- **附魔**：支持所有原版附魔，可添加多个附魔及等级。
- **属性修饰符**：可添加多个属性（如攻击伤害、移动速度等），支持三种操作类型（加法、倍率、最终值）和槽位设置。
- **药水效果**：可添加多个药水效果，设置等级、持续时间、粒子显示等，并自定义药水颜色。
- **烟花火箭**：设置飞行时间，添加多个爆炸效果（类型、颜色、淡出颜色、拖尾、闪烁）。
- **头颅生成器**：预设常用头颅（MHF 系列）或自定义纹理，可设置显示名称。
- **食物属性**：生成 `food` 和 `consumable` 组件，设置饥饿值、饱和度、进食时间、动画、音效及进食后效果。
- **旗帜属性**：选择底色，添加多层图案（最多 6 层）。
- **工具属性**：生成 `tool` 组件，设置默认挖掘速度、每方块耐久消耗，并添加自定义挖掘规则。
- **装备属性**：生成 `equippable` 组件，设置装备槽位、模型、声音、允许实体等；另支持滑翔、死亡保护等特殊功能。
- **成书生成器**：创建多页面成书，支持添加文本段落、目标选择器、记分板数据、绑定热键，编辑颜色、样式、鼠标点击/悬停动作。
- **其他属性**：不可破坏、损坏值、自定义模型数据、隐藏提示框、可破坏/可放置方块、修复材料、最大堆叠数、修复惩罚、使用冷却、实体数据等。
- **自动补全与搜索**：物品、附魔、方块、实体等下拉框支持输入搜索和模糊匹配。
- **可滚动标签页**：所有标签页均支持鼠标滚轮滚动，适应不同屏幕大小。

## 使用教程
 

### 1. 环境要求

- Python 3.8 或更高版本（开发环境运行）
- tkinter（Python 标准库自带，无需额外安装）

### 2. 运行程序

在项目根目录下执行：
python give.py
程序启动后，主窗口上方为物品配置和命令生成区，下方为标签页区域（默认收起，点击“完全展开标签页”按钮展开）。

### 3. 基本操作

1. **选择物品**：在“物品”下拉框中选择或输入中文名称，物品 ID 会自动填充；也可以直接输入物品 ID。
2. **设置数量**：在“数量”输入框中填写正整数。
3. **配置组件**：点击展开标签页，在各个标签页中根据需要添加组件数据。
4. **生成命令**：点击“生成 Give 命令”按钮，命令会显示在下方的文本框中。
5. **复制命令**：点击“复制”按钮将命令复制到剪贴板，然后粘贴到 Minecraft 聊天栏执行。

### 4. 打包为 exe（可在Releases中直接下载）

项目提供了 `MinecraftGiveGenerator.spec` 用于 PyInstaller 打包。打包前请确保：

- 所有代码文件位于项目根目录和 `py_files` 子目录。
- `command_block.ico` 图标文件存在于项目根目录。
- `MinecraftGiveGenerator.spec` 中的 `pathex` 路径已修改为你实际的项目路径。
在项目根目录打开命令提示符，执行：
pyinstaller MinecraftGiveGenerator.spec

## 自定义 ID 映射

所有物品、附魔、方块、实体、药水效果等 ID 均从 `txt_files` 目录下的文本文件中读取。文件格式为每行一条记录：
例如 `item_id.txt` 中的一行：
钻石剑, diamond_sword

**你可以直接编辑这些文件来添加、删除或修改 ID 映射。** 修改后重新启动程序即可生效。
> **注意**：部分 ID 可能缺失（特别是新版本内容），可以在 `txt_files` 中找到相应文件自行添加，请见谅。

## 常见问题

### 1. 打包后无法读取 `txt_files`？

请确保 `txt_files` 文件夹与 exe 文件位于同一目录。打包后的程序会自动在 exe 所在目录寻找 `txt_files`。

### 2. 某类物品或附魔下拉列表为空？

说明对应的 txt 文件可能未找到或格式错误。请检查 `txt_files` 是否存在，并确保文件编码为 UTF-8。### 3. 生成命令在游戏中无效？
本工具生成的命令使用 Minecraft 1.20.5-1.21.11 **物品组件**格式。请确认你的游戏版本符合要求。旧版本（1.20.4 及以下）不支持该格式。

## 已知问题与限制

- **ID 覆盖范围有限**：由于 Minecraft 更新频繁，部分新物品、附魔、实体等可能未包含在 `txt_files` 中。用户可自行添加。
- **成书生成器页面格式**：生成的页面 JSON 采用文本组件数组形式，部分旧版或特殊客户端可能显示异常，但原版 1.20.5+ 正常支持。
- **药水效果数字 ID 与命名空间 ID 并存**：代码中同时使用了数字 ID（用于旧格式转换）和命名空间 ID（用于新组件），对于部分新增效果可能未完全同步。
- **鼠标动作参数提示**：部分动作的参数输入框会显示提示文本，但用户输入时需手动清空，暂未实现自动填充默认值。
- **打包体积**：使用 PyInstaller 打包后 exe 文件较大（约 10-20 MB），属正常现象。
